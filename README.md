# OpenTelemetry Collector examples

Examples of OpenTelemetry Collector configurations. Mostly intended for use with Elastic Observability.

- [edot-tbs](./edot-tbs/) - EDOT collector with tail-based sampling, using Docker Compose
- [edot-inframetrics-terraform](./edot-inframetrics-terraform/) - EDOT collector on Kubernetes collecting pod metrics for the Kibana infrastructure inventory, using Terraform
